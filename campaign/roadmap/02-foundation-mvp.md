# 02 — Foundation / MVP

Core path:

`Identity → Listing → Marketplace → Order → Payment → Data persistence`

Focus:
- Core application and domain boundaries.
- Marketplace/listing lifecycle.
- Order lifecycle.
- Payment integration foundation.
- PostgreSQL/Redis/storage integration as required.
- Basic observability and deployment hygiene.

Exit criteria: critical user journey works end-to-end, automated tests cover critical paths, deployment is reproducible, and known security gaps are tracked.
