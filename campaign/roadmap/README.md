# MyZubster Roadmap

Seven-screen roadmap specification.

1. Roadmap Overview — Vision → MVP → Beta → Production → Scale.
2. Foundation / MVP — identity, marketplace, listings, orders, core data and payment foundations.
3. Security & Infrastructure — Docker, onion boundaries, secrets, monitoring, backups and DDoS controls.
4. Payment & Escrow — order/payment lifecycle, held funds concept, release/dispute paths and reconciliation.
5. Beta & Validation — real-user testing, feedback, bug fixing, performance and security validation.
6. Production & Scale — availability, observability, queues/cache, horizontal scaling and disaster recovery.
7. Future / Expansion — mobile, API ecosystem, additional payment flows, reputation and automation.

Status labels should distinguish implemented, in progress and planned work. Roadmap is directional and should be updated against the current repository and deployment state.
