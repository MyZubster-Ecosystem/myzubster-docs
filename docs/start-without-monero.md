# Guida: Come Iniziare con MyZubster Senza Monero

## Introduzione

Non hai Monero (XMR)? Nessun problema! MyZubster offre diversi modi per iniziare a usare la piattaforma anche senza possedere criptovalute. Questa guida ti mostrerà tutti i percorsi disponibili.

## Metodo 1: Guadagna MYZ con le Bounty

Il modo più diretto per ottenere MYZ senza investire è partecipare alle bounty su GitHub.

### Come Funziona
1. Vai su [github.com/MyZubster-Ecosystem/MyZubsterGateway/issues](https://github.com/MyZubster-Ecosystem/MyZubsterGateway/issues)
2. Cerca le issue con label `bounty` e `good-first-issue`
3. Leggi la descrizione del compito
4. Commenta `/attempt #NUMERO` per prenotare la bounty
5. Completa il lavoro e apri una Pull Request
6. Una volta mergiata, riceverai MYZ sul tuo wallet

### Tipi di Bounty
| Tipo | MYZ | Difficoltà |
|------|-----|-----------|
| Documentazione | 50-100 | Facile |
| Traduzioni | 50-100 | Facile |
| Design/UI | 100-250 | Media |
| Sviluppo Backend | 150-500 | Medio-Difficile |
| Sicurezza | 500+ | Difficile |

## Metodo 2: Programma Ambassador

Diventa un Ambassador MyZubster e guadagna MYZ promuovendo il progetto.

### Attività Ricompensate
- Scrivere articoli sul blog
- Creare video tutorial su YouTube
- Condividere sui social media
- Partecipare alla community Telegram
- Aiutare nuovi utenti

Contatta il team su Telegram per candidarti.

## Metodo 3: Testnet e Airdrop

Periodicamente MyZubster organizza eventi testnet dove puoi guadagnare MYZ testando nuove funzionalità.

### Come Partecipare
1. Segui gli annunci su Telegram e GitHub
2. Registrati quando viene aperta una testnet
3. Completa le task richieste (test di transazioni, feedback, bug report)
4. Ricevi MYZ come ricompensa

## Metodo 4: Referral Program

Invita amici e sviluppatori su MyZubster e guadagna MYZ per ogni nuovo utente attivo.

1. Ottieni il tuo link referral dalla dashboard MyZubster
2. Condividilo con amici e colleghi
3. Quando si registrano e completano azioni, guadagni MYZ

## Wallet MYZ: Come Conservare i Tuoi Guadagni

Anche senza Monero, puoi creare un wallet per ricevere MYZ:

1. **Wallet Tari**: Il network nativo di MYZ. Crea un wallet usando l'app ufficiale Tari.
2. **Wallet sulla Piattaforma**: MyZubster fornisce un wallet integrato accessibile dopo la registrazione.

Il tuo indirizzo Tari sarà simile a: `12Nbmmm5g6AU3Uk9CNHRdauTD4KzA8mmiAStqpcnHN3sDDrFcb4wtmsYXZq8rptAbwoAaBLq8K9RgUyrfFTmZGib1U4`
