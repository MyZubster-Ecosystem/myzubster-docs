# Bounties — MyZubster Documentation

This repository follows the canonical [MyZubster Bounty System](https://github.com/MyZubster-Ecosystem/myzubster/blob/main/BOUNTIES.md).

## Eligible scope

Documentation bounties may cover architecture docs, onboarding, API guides, tutorials, translations, diagrams, status audits and reproducible runbooks.

## Acceptance

Documentation must match current code/verified deployment state. It must clearly distinguish production, development, testnet, simulation, experimental and proposed functionality.

Do not copy historical payout claims into current documentation without independent evidence.

## Reward truth

MYZ in the current core platform is an internal reward/accounting ledger. A merged documentation PR does not prove external XMR/token settlement.

## Security

Use placeholders for credentials and never include real private keys, wallet seeds, tokens or confidential infrastructure data.

## Issues

Use this repository's GitHub issues and link the PR to the selected documentation bounty.
