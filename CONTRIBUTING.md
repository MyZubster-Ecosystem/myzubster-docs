## How to Contribute
1. **Fork the repo** and create your branch from `main`.
2. **Submit a Pull Request (PR)**: Ensure your PR describes the changes clearly.
3. **Documentation Format**: Please use clear, concise language. Use appropriate headers (`#`, `##`, `###`) to structure content.
4. **Markdown Style**:
   - Use standard GitHub Flavored Markdown.
   - Keep line lengths reasonable.
   - Use consistent indentation.
   - Link to other documents using relative paths.

## 🤖 Automation in this project

MyZubster uses automation to help manage the large volume of issues and PRs. Full governance and operational details are defined in [AI_CONTRACT.md](./AI_CONTRACT.md) and [BOT_CONTRACT.md](./BOT_CONTRACT.md).

### What is automated?
- Initial issue triage and labeling
- PR validation (tests, linting)
- Bounty status tracking
- Reminder comments

### How to identify automation
- Comments from @myzubster-bot
- The `automated` label
- Automated comments always include a disclaimer

### Human review
Despite automation, every PR is reviewed by a human maintainer before merge.
Bounty payments are manually approved and processed.

### Tips for contributors
- Don't worry if a bot comments on your PR - it's just running checks
- If you need human attention, ping a maintainer
- Bot comments are for information, not decisions
